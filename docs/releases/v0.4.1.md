# HDU-KillCourse NEXT v0.4.1

本次更新新增多账号管理与并行选课，可在同一个程序中登录多个账号，分别配置和运行选课任务。

## 新增功能

- **多账号管理**：支持添加、命名和切换账号，各账号独立保存登录信息、任务清单、课程资料和运行日志。
- **并行运行**：多个账号可以同时执行各自的任务。切换账号或停止其中一个账号，不会中断其他账号的任务。
- **批量启动**：支持勾选多个账号，核对各自的任务清单后统一启动，并分别显示启动结果。
- **复制清单**：添加账号时可复制已有账号的任务清单和执行参数，登录信息仍需单独配置。
- **兼容已有数据**：原有配置和日志会作为“默认账号”继续使用，无需手动迁移。

## 开始使用

在侧栏打开「账号与并行任务」添加账号，分别登录并配置任务。勾选需要运行的账号，点击「检查所选账号任务」，核对后即可并行启动。各账号的详细结果可在对应的「运行记录」中查看。

详细操作见 [多账号使用说明](../multi-account.md)。

## 下载与升级

请下载与设备对应的压缩包：Windows x64 / ARM64、macOS Intel / Apple Silicon 或 Linux x64 / ARM64。下载区同时提供 `SHA256SUMS.txt`，用于校验文件完整性。

从旧版升级时，请先停止所有任务并退出程序，备份并保留完整的 `data/` 目录，再替换程序文件。如果使用了自定义数据目录，请继续使用原有路径。

# HDU-KillCourse NEXT v0.4.1

本次为正式 Release，新增多账号并行选课。v0.4.0 构建时前端测试在较慢的运行器上超时，未发布；本版本修正测试的异步加载等待。

## 更新内容

- 每个账号独立登录，分别保存任务清单、执行参数、课程资料和运行日志。
- 运行中可以切换账号；停止一个账号不会影响其他账号。
- 支持检查多个账号各自的任务清单，确认后并行启动，并分别反馈启动结果。
- 添加账号时可复制已有清单和执行参数，不复制登录凭据。
- 原有数据保留为“默认账号”，无需手动迁移。
- 防止切换账号后的旧响应覆盖当前界面，并为登录与扫码结果增加有效性检查。

使用方法见 [多账号说明](../multi-account.md)。

## 下载与升级

提供 Windows x64 / ARM64、macOS Intel / Apple Silicon、Linux x64 / ARM64 六种压缩包，以及 SHA256SUMS.txt 校验文件。请下载与系统和架构对应的文件。

升级前停止正在运行的任务并退出旧程序。保留原数据目录，解压并启动新版即可。

## 验证

48 项 Rust 测试、15 项前端测试通过；包含模拟教务服务下的并发请求、Cookie 与日志隔离，以及单账号停止测试。未进行真实教务选退课联调。

# HDU-KillCourse NEXT v0.3.0

本版增加任务清单 JSON 导入导出、按运行批次保存和查看日志，并改进课程下载与代码组织。

## 功能与修复

- 启动任务成功后立即切换到运行记录页面。
- 每次运行的日志独立保存到本地 `data/logs/`，启动新任务或重启程序后仍可选择旧批次并分页查看。
- 课程结果记录课程名、教学班编号、上课时间及选课或退课操作；成功、失败和结果未知都有对应说明。
- 支持通过 JSON 导入任务清单，以及导出当前清单。导入文件先整体验证再追加，失败保留原内容；导入不会自动保存或启动任务。格式见 [任务清单 JSON 格式](../task-list-format.md)，发布包附带 `examples/task-lists.json`。
- 教务课程下载改为请求较大分页并启用 gzip，同时检查总数和重复页，减少请求开销并避免保存不完整资料。实际速度仍取决于学校响应和网络。
- 项目名称统一为 HDU-KillCourse NEXT，各页面说明改为操作指引。

## 维护与文档

- 拆分前端页面、操作 hook 和辅助函数，按功能拆分 Rust 本机 API 与学校客户端。
- 统一格式，删除未使用代码，修正与实现不符的注释，并加入格式和未使用代码检查。
- 增加 [代码结构与执行流程](../code-structure.md)，更新维护指南和 Protocol Review。

## 下载与升级

提供 Windows、macOS、Linux 的 x64 和 ARM64 六种压缩包，另附 `SHA256SUMS.txt`。下载时按系统和处理器架构选择；Windows 运行 `hdu-course-server.exe`，macOS / Linux 运行 `hdu-course-server`。

升级前先停止任务并退出旧服务，备份原程序旁的 `data/`，再将其保留在新程序旁；使用 `HDU_DATA_DIR` 时继续指向原目录。旧日志缺少操作字段时显示“操作未记录”。正在执行的任务不能跨重启恢复。

本版沿用预览版本状态。自动测试不使用真实学校凭据，也不代表完成真实选退课联调；先退后选不具备原子性，学校返回成功后仍需核对已选记录。

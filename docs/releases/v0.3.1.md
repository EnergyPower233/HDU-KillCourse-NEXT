# HDU-KillCourse NEXT v0.3.1

修复某门课程提交结果不明时终止整轮任务的问题。现在该次提交按失败记录，跳过当前课程并继续其他任务。

## 本次修复

- 选课返回非标准结果、无法解析的正文，或提交发生网络异常时，记录“选课失败”和具体原因，继续处理后续课程。
- 退课结果不明时，跳过该任务剩余退课及配对选课，继续下一个独立任务；已经成功的退课不会自动恢复。
- 蹲课模式从待处理集合移除本次提交失败的课程，继续查询和提交其他课程，不自动重复提交已跳过的课程。
- 日志保留课程身份、操作类型和不明原因；手动停止仍会等待在途提交结果并阻止后续提交。
- 根据原 Go v1.4.9 源码更新 [Protocol Review](../protocol-review.md)，补充本地模拟学校接口的回归测试。

“不明提交按失败处理”是本次任务的处理规则。人数可能已满，但不能仅凭不明结果认定满员或确认学校实际状态；请核对教务系统已选记录。

## 同时包含

本版包含 v0.3.0 的任务清单 JSON 导入导出、按运行批次持久化日志、课程下载优化、页面和后端模块拆分，以及代码结构文档。完整介绍见 [v0.3.0 更新说明](v0.3.0.md)。

## 下载与升级

提供 Windows、macOS、Linux 的 x64 和 ARM64 六种压缩包，附 `SHA256SUMS.txt`。Windows 运行 `hdu-course-server.exe`；macOS / Linux 运行 `hdu-course-server`。

升级前停止任务并退出旧服务，备份并保留原程序旁的 `data/`；使用 `HDU_DATA_DIR` 时继续指向原目录。正在执行的任务不能跨重启恢复。

本版沿用 Pre-release 状态。自动测试不使用真实学校凭据，不代表完成真实选退课联调。

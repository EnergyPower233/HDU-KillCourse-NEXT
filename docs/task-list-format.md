# 任务清单 JSON 格式

在「选课任务」页点「导入清单 JSON」选择文件。成功后追加到已有清单末尾，切换到第一个导入的清单；核对内容后点「保存清单」。导入不会启动选退课，也不会改动登录凭据、课程资料库或全局时间参数。失败时整份文件不导入。

点「导出当前清单」可获得包含当前编辑内容的 JSON，不要求先保存。示例见 [task-lists.json](../examples/task-lists.json)。示例中的课程编号是占位值，必须替换为教务课程资料中的真实值；推荐先在界面建立清单再导出。

## 文件结构

```json
{
  "version": 1,
  "year": 2026,
  "term": 1,
  "lists": [
    {
      "name": "我的清单",
      "mode": "watch",
      "tasks": [
        {
          "course": {
            "jxbmc": "(2026-2027-1)-REPLACE-CLASS",
            "kch_id": "REPLACE-COURSE-ID",
            "jxb_id": "REPLACE-CLASS-ID",
            "kcmc": "课程名称",
            "kklxmc": "主修课程"
          },
          "drops": []
        }
      ]
    }
  ]
}
```

| 字段            | 含义                                                            |
| --------------- | --------------------------------------------------------------- |
| `version`       | 格式版本，必须为数字 `1`                                        |
| `year` / `term` | 学年起始年 / 学期（1 或 2），须与当前偏好设置一致               |
| `lists`         | 1～100 个清单的数组                                             |
| `name`          | 清单名称，非空且不超过 100 字符；允许同名清单，导入时仍追加     |
| `mode`          | `watch` 蹲课，或 `once` 单次                                    |
| `tasks`         | 按执行顺序排列，单个清单最多 100 项；空清单可以导入，但不能执行 |
| `course`        | 要选的课程对象；仅退课时填写 `null`                             |
| `drops`         | 先退课程对象数组，纯选课时为 `[]`                               |

每门课程必须有非空字符串 `jxbmc`（教学班编号）、`kch_id`（课程内部编号）、`jxb_id`（教学班内部编号）。不要把课程名称当作内部编号。`jxbmc` 必须属于文件指定学期，例如以 `(2026-2027-1)-` 开头。

可选字符串字段：`kcmc` 课程名、`kklxmc` 课程类型、`sksj` 上课时间、`jzgxx` 教师、`jxdd` 地点、`jxbzc` 面向班级。省略时为空字符串。执行时需要受支持的课程类型：主修课程、通识选修课、体育分项、特殊课程；导入仅检查结构与清单规则，不向学校验证课程是否存在或可选。

## 选退课规则

- 纯选课：`course` 为课程对象，`drops: []`；两种模式均支持。
- 先退后选：`course` 为目标课程，`drops` 填先退课程；必须为 `once`。
- 仅退课：`course: null`，`drops` 至少一门课；必须为 `once`。
- 一个任务不能同时没有选课和退课。同一清单内教学班不能重复，包括选课与退课之间；不同清单可以包含相同课程。
- 先退后选不保证原子性，退课成功后选课失败不会自动恢复旧课。

文件采用 UTF-8 JSON，最大 1 MB，支持 UTF-8 BOM；不接受注释、尾随逗号或未知字段。此格式是清单交换文件，不能直接导入 `data/settings.json`、课程缓存 `course.json` 或含凭据的配置文件。

全局查询间隔、波动、定时开始和提前重登仍使用当前偏好设置。导入追加的清单在点「保存清单」或成功保存并启动任务后才写入 `data/settings.json`。
